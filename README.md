# Russian Interest Rate Models

Исследовательский проект: исторические процентные ставки России, модели Vasicek и CIR и проверка их прогнозной способности.

## Установка

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux / macOS: source .venv/bin/activate
python -m pip install -e ".[dev]"
```

## Загрузка данных

```bash
# Все три ряда, с 01.01.2014 по текущую дату:
python -m russian_rates

# Только RUONIA за конкретный период:
python -m russian_rates --series ruonia --start 2014-01-01 --end 2026-11-20

# Кривая бескупонной доходности ОФЗ:
python -m russian_rates --series zcyc --start 2022-01-01

# Заменить накопленную историю только запрошенным периодом:
python -m russian_rates --series key_rate --start 2020-01-01 --replace
```

Принимаются даты `YYYY-MM-DD` и `DD.MM.YYYY`. По умолчанию данные сохраняются в `data/processed/` (не включается в Git). Запросы разбиваются по календарным годам, ограничены по времени и повторяются при временных HTTP-ошибках (429/5xx). Парсер отвергает неожиданные структуры и неверные числа вместо молчаливого сохранения повреждённых данных.

Повторная загрузка **дополняет существующую историю**: совпадающие даты/сроки заменяются новыми значениями. `--replace` полностью заменяет историю выбранным периодом. Запись осуществляется через временный файл с последующей атомарной заменой.

| Parquet | Поля |
| --- | --- |
| `ruonia.parquet` | `date`, `ruonia_pct`, `volume_bln_rub` |
| `key_rate.parquet` | `date`, `key_rate_pct` |
| `zcyc.parquet` | `date`, `tenor_years`, `yield_pct` |

КБД хранится в **длинном формате**: по 12 сроков от 0,25 до 30 лет на дату. Даты имеют тип `datetime64[ns]`, числовые показатели — `float64`. Все ставки и доходности — **в процентах годовых**, например `14.25`, а не `0.1425`; для стохастических моделей их обычно делят на 100. В данных сохраняются даты наблюдений; пропуски выходных и праздников автоматически не заполняются. Для RUONIA отсутствующий объём сделок (символ `—`, `–` или `-` в ответе ЦБ) сохраняется как `NaN`; сама ставка остаётся обязательной. Нули и значения с соседних дат не подставляются.

## Использование в Python

```python
import pandas as pd

ruonia = pd.read_parquet("data/processed/ruonia.parquet")

zcyc = pd.read_parquet("data/processed/zcyc.parquet")
curve = zcyc.pivot(index="date", columns="tenor_years", values="yield_pct")
```

Важные методологические решения:
- RUONIA — основной ряд, его даты не фильтруются по календарю КБД;
- разность RUONIA и ключевой ставки рассчитывается по последней уже
  известной ключевой ставке, без использования будущих дат;
- пропущенные объёмы RUONIA допустимы, пропущенные процентные ставки —
  сигнал о проблемах в выгрузке;
- статистики за отдельные периоды описывают данные, **но не являются**
  оценками параметров Vasicek/CIR и не доказывают стационарность ряда.

## Калибровка и диагностика Васичека

В ноутбуке [notebooks/02_vasicek_calibration.ipynb](notebooks/02_vasicek_calibration.ipynb)
выполнена оценка классического Vasicek по RUONIA с учётом реальных интервалов между датами.
Ноутбук содержит точный MLE и профильную оценку, проверку устойчивости к начальным условиям,
анализ исторических периодов, номинальные профильные интервалы, диагностику
стандартизированных остатков, ARCH/Ljung–Box и сопоставление с решениями Банка России.

**Результат сохранённой калибровки за 2014–2026 годы:**
скорость возвращения \(a\approx0{,}7788\) 1/год, уровень \(b\approx11{,}33\%\),
волатильность \(\sigma\approx5{,}67\) п.п./√год, half-life ≈10,68 мес.
Номинальный профильный 95%-й интервал для \(a\) — [0,1061; 1,4534].

**Содержательный вывод:** нормальная модель с неизменными параметрами
плохо описывает экстремальные изменения RUONIA; небольшое число крупных шоков
существенно влияет на хвосты распределения. Даты изменения ключевой ставки
связаны с более крупными остатками, но простой календарный анализ не доказывает причинность.
Периоды частично перекрываются, а доверительные интервалы опираются на предположения
классической модели, которые могут нарушаться. AIC описывает внутривыборочную подгонку,
а не качество будущих прогнозов.

### Переиспользуемая модель Vasicek

Математические функции находятся в файле
[src/russian_rates/models/vasicek.py](src/russian_rates/models/vasicek.py).
Они применимы к RUONIA и к спреду RUONIA − ключевая ставка.

~~~python
import pandas as pd
from russian_rates.models import (
    calibrate_profile, prepare_transitions, standardized_residuals,
)

df = pd.read_parquet("data/processed/ruonia.parquet")
r_prev, r_next, dt = prepare_transitions(df, "ruonia_pct")
fit = calibrate_profile(r_prev, r_next, dt)

print(f"a = {fit['a']:.4f} 1/год")
print(f"b = {fit['b'] * 100:.4f}%")
print(f"sigma = {fit['sigma'] * 100:.4f} п.п./√год")
z = standardized_residuals(
    fit["a"], fit["b"], fit["sigma"], r_prev, r_next, dt
)
~~~

В ноутбуке про спред достаточно передать объединённый датафрейм и
колонку "spread_pp". Исходные значения в Parquet выражены в процентах;
функция prepare_transitions делит их на 100 по умолчанию. Для ставок,
уже переведённых в доли единицы, нужно указать values_in_percent=False.

Интервалы между наблюдениями учитывают календарные дни (/365).
Параметры оцениваются в исторической мере P; их нельзя напрямую
использовать для безарбитражной оценки облигаций без перехода
к риск-нейтральной мере Q. Номинальные профильные доверительные интервалы
опираются на гауссовские предположения, проверяемые диагностикой остатков.

## Исследование спреда RUONIA − ключевая ставка

Ноутбук [03_ruonia_key_rate_spread.ipynb](notebooks/03_ruonia_key_rate_spread.ipynb)
продолжает изучение Васичека на спреде RUONIA − ключевая ставка ЦБ. В нём
разобраны историческая динамика и стационарность спреда (ADF/KPSS), реакция
на изменения ключевой ставки, профильная калибровка Vasicek,
распределение остатков и тестирование прогноза на отложенном периоде.

**Основные результаты сохранённого запуска:**

- Half-life спреда — примерно **4–6 календарных дней** в рассматриваемых
  исторических периодах, тогда как для абсолютной RUONIA он был гораздо длиннее.
- Тяжёлые хвосты остатков и зависимость абсолютных инноваций сохраняются;
  кризисные события 2014 года не объясняются исключительно изменением
  ключевой ставки.
- На обучении **2016–2024** и тесте **2025–2026** модель Naive показала
  наименьший MAE прогноза **RUONIA** на горизонтах от 1 до 60 наблюдений.
  Одношаговый MAE: Naive 0,08942 п.п.; Vasicek RUONIA 0,08989 п.п.;
  Vasicek Spread 0,10559 п.п.
- При прогнозировании **самого спреда** и последующем разбиении окон по
  фактическим изменениям ключевой ставки Vasicek Spread часто превосходит
  Naive Spread; однако изменения ключевой ставки заранее не известны,
  поэтому это не доказывает преимущества в прогнозе самой RUONIA.

Для повторного запуска нужны локальные файлы Parquet и установленный пакет.
Сохранённые графики и таблицы в ноутбуке видны на GitHub и не очищаются.
Значимость различий ошибок отдельно не проверялась, а данные RUONIA
становятся известны только после публикации; полноценный торговый
backtest требует учёта времени доступности информации.
